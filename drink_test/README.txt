DRINK TEST — локальный сайт-меню

Откройте index.html двойным щелчком, чтобы посмотреть сайт.

Файлы:
- index.html — структура страницы
- style.css — все стили и адаптивная верстка
- script.js — фильтры и карточка выбранной позиции
- assets/menu-sprite.png — изображения меню

Перед публикацией замените в index.html телефон, адрес и ссылки Glovo на реальные данные заведения.
